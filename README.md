## ✨ Features
 
- 🔒 Replaces your room code with `HIDDEN` across all `TextMeshPro`, `UI.Text`, and `TextMesh` components
- ♻️ Non-destructive — originals are restored when disabled
- 🖥️ Clean on-screen HUD with status indicator
- ⚡ Drop-in, no configuration needed
 
## 🎮 Controls
 
| Key  | Action               |
| ---- | -------------------- |
| `F8` | Toggle Streamer Mode |
| `F5` | Show / hide the HUD  |
 
## 📦 Installation
 
1. Install [BepInEx 5](https://github.com/BepInEx/BepInEx) for Gorilla Tag.
2. Drop `StreamerPlus.dll` into `BepInEx/plugins/`.
3. Launch the game and press `F8` to enable.
 
## 🛠️ Build
 
```sh
dotnet build StreamerPlus.csproj -c Release
```
 
Output: `bin/Release/StreamerPlus.dll`
